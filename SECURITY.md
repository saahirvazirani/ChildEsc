# Safety and Security

## Not an emergency service

ChildEsc is a research artifact. This repository and its issue tracker are not
monitored as a crisis-support channel. Do not post personal crisis disclosures,
contact information, identifying information about a child, clinical records,
or reports of ongoing abuse or exploitation.

If someone may be in immediate danger, contact an appropriate local emergency
or crisis service. ChildEsc cannot contact services or people on a user's
behalf.

## Reporting a software vulnerability

Use GitHub's private vulnerability-reporting feature when it is available for
this repository. Until then, contact the repository owner privately through
GitHub rather than opening a public issue. Include the affected version,
reproduction steps, impact, and any suggested mitigation. Do not include real
child data or live credentials in a report.

## Research-safety findings

Open an issue for reproducible concerns about benchmark labels, metrics, target
constraints, or documentation only when the report can use synthetic examples.
Mark urgent methodological concerns clearly, but do not describe the project as
a clinical or emergency system.

## Supported scope

The current release is a preliminary synthetic testbed. It has no supported
production deployment and no security-update service-level agreement.
